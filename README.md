# במה פתוחה — דף נחיתה

אתר סטטי בעברית, מתאים ל-GitHub Pages ולנייד. אין צורך בהתקנות או בשרת.

## העלאה ל-GitHub

1. צרו Repository חדש ב-GitHub, למשל `math-open-mic`, והגדירו אותו Public.
2. לחצו **Add file → Upload files** והעלו **את תוכן התיקייה** (לא את קובץ ה-ZIP). חשוב לשמור גם על התיקייה `assets` עם התמונה שבתוכה.
3. לחצו **Commit changes**.
4. ב-Repository היכנסו ל-**Settings → Pages**. בחרו **Deploy from a branch**, ענף `main`, תיקייה `/(root)`, ושמרו.
5. לאחר שהפרסום יסתיים, כתובת האתר תהיה בדרך כלל `https://USERNAME.github.io/math-open-mic/` (להחליף USERNAME בשם המשתמש).

## איך מעדכנים?

פתחו את `data.js` ב-GitHub ולחצו על סמל העיפרון (**Edit this file**). ערכו את הערכים ושמרו באמצעות **Commit changes**. העדכון יופיע באתר לאחר הפרסום מחדש (לרוב בתוך דקות).

- `date`: תאריך בפורמט `YYYY-MM-DD`.
- `time`: שעות האירוע.
- `location`: מיקום האירוע.
- `locationUrl`: קישור למפה, אופציונלי (כתובת https://).
- `announcement`: הודעה בולטת בראש האתר; השאירו ריק כדי להסתיר.
- `contact`: טקסט ליצירת קשר, אופציונלי.
- `intro` ו-`note`: הטקסטים שמופיעים ליד פרטי האירוע.
- `songs`: כל שורה היא שיר בפורמט `שם השיר|המבצע|en` או `שם השיר|המבצע|he`. אפשר להשאיר מבצע ריק (`Autumn Leaves||en`). אין צורך למספר: האתר ממספר אוטומטית.

**חשוב:** לא למחוק את הסימנים `|` המפרידים בין השדות או את סימני ה-` שמקיפים את רשימת השירים.

## קוד QR לפוסטר

רק לאחר שהאתר עלה וכתובתו סופית, יוצרים QR לכתובת האתר ומחליפים את הקוד הדקורטיבי בפוסטר. כאשר מעדכנים את `data.js`, הכתובת נשארת זהה ולכן אין צורך לשנות QR.

## פרטיות

GitHub Pages בריפו ציבורי הוא אתר ציבורי, וניתן לצפות בו גם בלי חשבון GitHub. אין באתר הרשמה או איסוף פרטים אישיים.
